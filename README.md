   # Playwright QA Portfolio - Sauce Demo

   Projeto de automação de testes com Playwright e TypeScript.

   ## Como rodar
   - npm install
   - npx playwright install
   - npx playwright test
   - npx playwright test

## Cenários cobertos

| Funcionalidade | Cenário | Tipo |
| --- | --- | --- |
| Login | Login com usuário válido | Positivo |
| Login | Login com usuário bloqueado | Negativo |
| Login | Login sem senha | Negativo |
